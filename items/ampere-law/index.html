Ampère's Law

Statics Magnetostatics Est. 1826

Ampère's law states that the line integral of $\mathbf{B}$ around any closed loop equals $\mu_0$ times the total current threading the loop. Use the slider below to adjust the Amperian loop radius and watch the circulation integral remain constant.

Loop Radius: 2.0

Overview

Ampère's circuital law is one of Maxwell's four equations. In its integral form it relates the circulation of $\mathbf{B}$ around a closed path to the current enclosed by that path. When the geometry has sufficient symmetry (infinite wire, solenoid, toroid), Ampère's law lets you find $\mathbf{B}$ without performing a full Biot-Savart integration.

The key insight: the circulation $\oint\mathbf{B}\cdot d\boldsymbol{\ell}$ depends only on how much current passes through the loop, regardless of the loop's shape or the field distribution outside.

When to Use

  • Systems with cylindrical, planar, or toroidal symmetry
  • Infinite straight wires, solenoids, and toroids
  • Quick estimation of B without integration

Key Properties

  • Path independence — Circulation depends only on $I_{\text{enc}}$, not the loop shape
  • Symmetry exploitation — Choose a loop where B is constant along the path
  • Differential form — $\nabla \times \mathbf{B} = \mu_0 \mathbf{J}$ (current is the source of curl of B)
  • Maxwell's extension — Adding $\mu_0\varepsilon_0\partial\mathbf{E}/\partial t$ gives the full Ampère-Maxwell law

Strengths

  • Elegant shortcut for symmetric problems
  • Directly reveals the role of enclosed current
  • Foundation for understanding solenoids and inductors

Limitations

  • Only useful when sufficient symmetry exists
  • Does not give direction information directly
  • Static form incomplete without displacement current

How It Works

The visualization shows the magnetic field from one or more long straight wires (current out of the page). A dashed circular Amperian loop is drawn around the origin. Small arrows on the loop show $\mathbf{B}\cdot d\boldsymbol{\ell}$ at sample points.

  1. B field vectors: Computed from the Biot-Savart formula for infinite wires and drawn as a vector field on a grid.
  2. Amperian loop: A circular path of adjustable radius centered on the wire. The code numerically evaluates $\oint \mathbf{B}\cdot d\boldsymbol{\ell}$ by summing $B_\theta \cdot r\,d\theta$ around the loop.
  3. Verification: The numerical integral is displayed alongside the theoretical value $\mu_0 I_{\text{enc}}$. For a single wire at the origin these always agree, confirming Ampère's law.

Key Equations

Ampère's Law (Integral Form)

$$\oint_C \mathbf{B} \cdot d\boldsymbol{\ell} = \mu_0 I_{\text{enc}}$$

Ampère's Law (Differential Form)

$$\nabla \times \mathbf{B} = \mu_0 \mathbf{J}$$

B from Infinite Wire (via Ampère)

$$B(2\pi r) = \mu_0 I \implies B = \frac{\mu_0 I}{2\pi r}$$

Solenoid Interior Field

$$B = \mu_0 n I$$

Ampère-Maxwell (Full Form)

$$\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}$$

Python Implementation

Python
import numpy as np

def compute_circulation(B_field_fn, loop_center, radius, n_samples=200):
    """Compute the line integral of B around a circular loop.

    Args:
        B_field_fn: callable(x, y) -> (Bx, By)
        loop_center: (cx, cy)
        radius: loop radius
        n_samples: number of sample points on loop

    Returns:
        circulation: float, the line integral of B dot dl
    """
    cx, cy = loop_center
    dtheta = 2 * np.pi / n_samples
    circ = 0.0

    for i in range(n_samples):
        theta = i * dtheta
        # Point on loop
        px = cx + radius * np.cos(theta)
        py = cy + radius * np.sin(theta)
        # Tangent direction (dl direction)
        tx, ty = -np.sin(theta), np.cos(theta)
        # B field at this point
        Bx, By = B_field_fn(px, py)
        # B dot dl  (dl = r * dtheta * t_hat)
        circ += (Bx * tx + By * ty) * radius * dtheta

    return circ

def B_infinite_wire(x, y, wire_x=0, wire_y=0, current=1.0):
    """B field from an infinite wire at (wire_x, wire_y)."""
    mu0_over_2pi = 2e-7
    dx, dy = x - wire_x, y - wire_y
    r2 = dx**2 + dy**2
    if r2 < 1e-10:
        return 0.0, 0.0
    Bx = -mu0_over_2pi * current * dy / r2
    By =  mu0_over_2pi * current * dx / r2
    return Bx, By

# Verify Ampere's law: circulation should equal mu0 * I_enc
I = 1.0
R = 2.0
circ = compute_circulation(
    lambda x, y: B_infinite_wire(x, y, current=I),
    (0, 0), R
)
mu0 = 4e-7 * np.pi
print(f"Numerical: {circ:.6e}")
print(f"mu0 * I:   {mu0 * I:.6e}")
