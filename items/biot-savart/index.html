Biot-Savart Law

Statics Magnetostatics Est. 1820

The Biot-Savart law gives the magnetic field $\mathbf{B}$ produced by a steady current element. For an infinite straight wire the field forms concentric circles, with magnitude falling off as $1/r$. Add wires below to see how the fields superpose.

Current-carrying wires shown as circles. Dot = current out of page, cross = current into page.

Overview

The Biot-Savart law is the magnetic analogue of Coulomb's law. It gives the magnetic field $\mathbf{B}$ at a point in space due to a small current element $I\,d\boldsymbol{\ell}$. The field involves a cross product, so $\mathbf{B}$ circulates around the current rather than pointing radially.

For an infinitely long straight wire carrying current $I$, the Biot-Savart integral yields $B = \mu_0 I / (2\pi r)$, directed tangentially around the wire. The right-hand rule determines the circulation direction.

When to Use

  • Computing the B field from arbitrary current distributions
  • Finite-length wire segments, current loops, or complex geometries
  • Cases where symmetry is insufficient for Ampère's law

Key Properties

  • Cross-product geometry — $d\mathbf{B} \propto Id\boldsymbol{\ell}\times\hat{\mathbf{r}}$, so the field circulates
  • Inverse-square law — Each element contributes $\propto 1/r^2$; the infinite wire sums to $1/r$
  • Linear superposition — Fields from multiple wires add as vectors
  • Solenoidal field — $\nabla \cdot \mathbf{B} = 0$ (no magnetic monopoles)

Strengths

  • Works for any current geometry
  • Exact for steady currents
  • Intuitive right-hand-rule interpretation

Limitations

  • Integral can be difficult to evaluate analytically
  • Only valid for magnetostatics (steady currents)
  • Singularity at the wire location

How It Works

The visualization shows the magnetic field in the plane perpendicular to infinitely long straight wires. Each wire carries current either out of the page (dot) or into the page (cross).

  1. Vector arrows: At each grid point the total $\mathbf{B}(x,y)$ is computed by summing the contribution of every wire. For a wire at position $(x_w, y_w)$ carrying current $I$ out of the page, $\mathbf{B} = \frac{\mu_0 I}{2\pi r^2}(-\Delta y, \Delta x)$.
  2. Current indicators: Wires are drawn as filled circles. A dot indicates current flowing out of the page; a cross indicates current flowing into the page.
  3. Superposition: When multiple wires are present the total field is the vector sum. Parallel currents attract; antiparallel currents repel.

Key Equations

Biot-Savart Law

$$d\mathbf{B} = \frac{\mu_0}{4\pi}\frac{I\,d\boldsymbol{\ell}\times\hat{\mathbf{r}}}{r^2}$$

Biot-Savart Integral

$$\mathbf{B}(\mathbf{r}) = \frac{\mu_0}{4\pi}\int \frac{I\,d\boldsymbol{\ell}'\times(\mathbf{r}-\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|^3}$$

Infinite Straight Wire

$$B = \frac{\mu_0 I}{2\pi r}$$

No Magnetic Monopoles

$$\nabla \cdot \mathbf{B} = 0$$

Vector Potential

$$\mathbf{B} = \nabla \times \mathbf{A}, \qquad \mathbf{A}(\mathbf{r}) = \frac{\mu_0}{4\pi}\int\frac{\mathbf{J}(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|}\,dV'$$

Python Implementation

Python
import numpy as np

def biot_savart_wire(r, wire_pos, current, direction='out'):
    """Compute B field at position r from an infinite straight wire.

    The wire is along the z-axis at (wx, wy). In the xy-plane the
    field circulates around the wire with magnitude mu0*I/(2*pi*r).

    Args:
        r: (2,) array, observation point [x, y]
        wire_pos: (2,) array, wire position [wx, wy]
        current: float, current magnitude (A)
        direction: 'out' or 'in' (out of / into page)

    Returns:
        B: (2,) array, magnetic field [Bx, By]
    """
    mu0_over_2pi = 2e-7  # mu0 / (2*pi)
    dr = r - wire_pos
    dist2 = np.dot(dr, dr)
    if dist2 < 1e-10:
        return np.zeros(2)
    sign = 1.0 if direction == 'out' else -1.0
    # B = (mu0*I)/(2*pi*r^2) * (-dy, dx)
    Bx = -sign * mu0_over_2pi * current * dr[1] / dist2
    By =  sign * mu0_over_2pi * current * dr[0] / dist2
    return np.array([Bx, By])

def superposition_B(grid_x, grid_y, wires):
    """Compute B on a 2D grid from multiple wires."""
    Bx = np.zeros_like(grid_x)
    By = np.zeros_like(grid_y)
    for i in range(grid_x.shape[0]):
        for j in range(grid_x.shape[1]):
            pos = np.array([grid_x[i,j], grid_y[i,j]])
            for w in wires:
                B = biot_savart_wire(pos, w['pos'], w['I'], w['dir'])
                Bx[i,j] += B[0]
                By[i,j] += B[1]
    return Bx, By

# Example: two parallel wires
wires = [
    {'pos': np.array([-1.5, 0.0]), 'I': 1.0, 'dir': 'out'},
    {'pos': np.array([ 1.5, 0.0]), 'I': 1.0, 'dir': 'out'},
]

x = np.linspace(-5, 5, 20)
y = np.linspace(-5, 5, 20)
X, Y = np.meshgrid(x, y)
Bx, By = superposition_B(X, Y, wires)
